## 运行时验收

以 `cargo run --example runtime_smoke` 创建隔离临时工作区、真实命令型服务、PTY 与 SQLite 数据库。该程序不使用用户已有服务，也不发起模型请求。本机完整运行通过，成功后自动删除临时数据：

- 空数据库、默认 Agent 配置、中文服务与文档保存。
- 两服务分别使用中文与空格目录、不同环境和 TCP／UDP 端口；重复启动不会产生第二个受管实例。
- 没有前端消费者时，超过 2 MiB 缓存容量的大量输出不会卡住服务；随后恢复有序输出并收到明确的历史截断提示。
- 其他服务占用预期端口时只报告冲突，不计为当前服务实际端口；目录失效与快速命令失败保留异常原因与退出码。
- 独立终端的中文输入、尺寸调整，以及服务与交互终端使用已有 Python venv。
- 停止一个服务会回收其子进程，同时保留另一服务和当前服务的独立终端；立即重启获得新的运行标识。
- 向不读取输入的终端发送 512 KiB 数据后，停止流程仍可执行；忽略中断的进程等待五秒后被强制清理。
- 主动脱离受管 session 且仍持有 PTY 的验收子进程不会让输出回收无限等待，也不会被正式运行时越界终止；验收程序单独清理自己创建的脱离进程。
- 本机已安装的 Claude Code 在独立 PTY 中执行 `--version`，输出非空、退出码为零。
- 统一退出会清理全部受管会话；删除服务时级联删除应用内文档。

验收中修复了启动失败状态遗漏、快速退出时的进程组检查竞态，以及输入拥塞阻止停止的问题。运行该验收需要允许枚举和管理本程序创建的子进程；受限沙箱会影响这些系统操作。

- 未配置发布签名、公证或自动更新。

Windows 引导器先以暂停状态创建目标进程，纳入独立 Job 后再执行；目标前的同程序 helper 由 `portable-pty` 显式关联 ConPTY，并检查控制台输入、输出设备。实现依据 Microsoft 的[伪控制台创建说明](https://learn.microsoft.com/en-us/windows/console/creating-a-pseudoconsole-session)与[控制台继承规则](https://learn.microsoft.com/en-us/windows/console/creation-of-a-console)；GUI 子系统的 release 构建仍须在 Windows 上实际验收，文档核查不能替代运行结果。

隔离 Windows 类型检查已覆盖本项目的 portable-pty 本地补丁：不请求继承父控制台光标，并纠正终止 API 的返回值判断。关闭时保持输出读取并先关闭 ConPTY master，规避旧版 Windows 的输出管道回收等待；具体上游差异与许可证见[补丁说明](../src-tauri/vendor/portable-pty/补丁说明.md)。

## 人工验收建议

1. 使用两个实际项目创建服务，启动后确认状态、真实端口与服务输出；停止一个时另一个继续运行。
2. 每个服务打开普通终端与 Agent。使用中文输入法、复制粘贴、Ctrl+C；切换服务、标签和主题，确认原会话仍在。
3. 在大量输出时隐藏窗口，再从托盘恢复；确认服务继续工作。
4. 编辑服务配置或文档后使用托盘退出，检查未保存提示；确认保存后重开只恢复配置，不自动启动服务。
5. Windows 须分别验收 PowerShell、cmd、npm 安装的 `.cmd` Agent、带中文和空格的目录，以及忽略中断的子进程树清理。

代码审查入口见[架构与人工审查说明](./架构与人工审查.md)。

## 2026-09-21：现有服务发现与接入

新增 `discovery_smoke`，在临时目录启动本验收程序自己的服务，未接入或停止用户已有服务。macOS Intel 已完成以下真实流程：

- 同一进程的 TCP、UDP、IPv6 端口正确归属，多个端口归为一个实例；缺少启动目录和命令也可接入，重复关联被拒绝。
- 使用同 PID、不匹配创建时间的旧快照执行停止，不会影响实际运行进程。
- 清理平台运行时、删除外部记录后，外部服务继续响应；重新打开数据库与跟踪器可恢复仍匹配的关联。
- 无效目录使转换在停止旧进程之前失败；单独停止一个外部服务不影响另一服务。
- 同端口再次出现的新进程不会继承旧记录；明确重新关联后才可停止。
- 预期端口被占用时取消转换，来源仍为外部；释放端口后可创建新的受管实例，清理托管会话不影响其他外部进程。
- 自建 Python 内嵌脚本归入待确认，未解锁时停止请求被拒且进程继续运行；解除保护后可停止。使用同一数据库新建跟踪器不继承解锁状态。
- 同一 Python 实例主动关闭唯一监听端口后，实际端口列表变空，但运行状态仍为运行中。

验收修正了 macOS 祖先遍历在 PID 1 处遇到权限限制，以及 zombie 已退出进程的状态判断。该流程不代表 macOS 系统服务已实际执行停止；系统与共享宿主的保护逻辑通过代码审查和受控样例验证，未终止真实系统组件。
