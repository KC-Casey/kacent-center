# 架构与人工审查说明

## 变更范围

从空目录建立 Tauri 2 桌面工程，按已确认的深浅主题设计实现中文服务列表、服务配置、环境页、文档编辑和独立终端。后端拥有运行状态，前端不会把按钮点击或预期端口伪装成实际运行结果。

## 本次新增：端口发现与外部接入

发现模块与 PTY 运行时共享端口快照；外部进程没有伪造的 PTY 或 Child 句柄。SQLite 版本 2 为旧记录补上 managed 来源，external 记录可暂缺启动配方，但必须有 PID 与创建身份。普通编辑不能改写来源或身份；只有经核验的接入和转换命令可变更。

优先审查 `discovery/` 的原生身份核验、分类与单进程终止，以及 `external.rs` 的发布前身份复核和转换失败处理。系统与待确认项的临时解锁只保存在内存，共享宿主不能解除只读；端口号、用户名或解释器路径不能单独作为系统组件判据。

停止外部服务只作用于选中的 PID。删除或退出只清理平台拥有的会话；外部进程继续运行。应用重开时重新核验原实例，PID 复用或后台重新拉起的新实例不继承关联。转换前校验完整配方，确认原实例退出及预期端口释放，再创建新的受管进程；创建失败保持外部来源。

Windows 外部停止使用同一个进程句柄读取创建时间并终止。macOS 使用 libproc 的微秒创建时间，紧邻每次单 PID 信号重新核验；POSIX 的身份查询与发信号不是一个原子操作，不能将这种尽力核验描述为内核级的绝对防复用保证。发现器也在端口扫描前后校验进程代际，身份不足的端口降为未归属，不把权限错误当作进程退出。

发现列表新增进程族展示分组，解决 PostgreSQL 主进程和工作进程共享端口时出现多条服务的问题。后端只给出经过身份复核的分组根，要求快照内明确父子关系、相同可执行文件和分类；脚本解释器还要求工作目录与脚本来源一致，共享宿主保持独立。前端按协议与端口汇总地址和所有者，接入时仍提交原始成员的身份及端口。分组不持久化，也不扩大停止范围；没有足够证据、父节点不在监听快照内或父节点已退出时保持分开。

## 建议的审查顺序

### 终端外观与工具预设扩展（2026-09-22）

数据库版本 4 在偏好表保存独立的 `terminal_json`；旧主题、服务、文档和已修改的 Agent 配置继续保留。终端默认直接跟随操作系统深浅模式，与工作台固定主题独立。保存前在独立的 xterm 中预览，保存成功后更新所有现有实例的 options，并对已挂载实例重新计算行列；不重建 PTY、不重订阅输出，也不清空回滚区。隐藏的实例保留配置，切回时重新测量；终端收起再展开时重新挂载已有 DOM。

人工审查入口为 `src/components/SettingsDrawer.tsx` 的草稿与退出保护、`src/terminalAppearance.ts` 的默认值和校验，以及 `src/terminals.ts` 的原位外观更新。颜色编辑会以当前实际配色为起点切换至自定义。无效颜色、字体或数值在前后端都被拒绝；工具自身输出的真彩色界面仍遵循工具自己的设置。

`assets/agent-presets.json` 为前端模板和 Rust 数据迁移提供同一份九项目录。Rust 在编译时嵌入目录，不在运行时扫描工作目录寻找预设。新库初始化全目录；旧库只补入缺少的新六项，按 ID、名称和程序 basename 去重，不覆盖已修改的路径、参数或环境，原三项已删除工具不复活。升级完成后删除预设，重开也不会再次插入。预设不触发安装、登录、检测命令执行或模型请求；ZCode 明确对应 Z.ai 的 CLI 版本。

### 多类型服务扩展

`kind` 与类型化 `launch` 描述启动方式，`source` 继续描述接入来源；两者不能互相替代。版本 3 迁移为旧记录补上命令类型，同时建立独立的桌面应用实例关联表。启动/重启接口返回运行态和可选终端，前端不得再假定每次启动都创建 PTY。

前端项目复用原来的独立 PTY、环境和进程清理，包管理器、脚本名与参数按独立参数传递。项目识别只读取 JSON 与锁文件，不执行脚本。静态站点由本程序专用子进程入口运行，各站点有自己的 PID 和监听端口；入口早于 Tauri 单实例初始化，避免预览进程被主窗口的单实例机制拦截。

前端项目启动为包管理器设置禁止隐式安装或下载工具链的私有环境。macOS 图形界面启动时只补充交互登录 shell 的 PATH，读取有超时与大小上限，不读取外部进程环境。静态文件请求检查规范化路径、符号链接与 SPA 入口；同权限本地进程在检查与实际打开文件之间并发替换符号链接，仍存在时间窗口，因此不能将其视为对恶意本地写入者的文件系统沙箱。

桌面应用管理与 PTY/静态站点清理严格分开。中心退出和记录删除只释放观察关系，不终止桌面应用。应用正常退出请求、强制结束和窗口激活各自核验原生身份；正常请求超时不能自动升级为强杀。跨进程交接无法确认时保留未知状态，不按名称或单独 PID 猜测关联。

Windows 启动时保留进程句柄，持久化只保存 PID、原生创建时间和规范化目标路径；释放句柄不会终止应用。macOS 按实际应用路径与原生实例核验，同 Bundle ID 的不同安装副本不能互相替代。运行中的应用不能切换目标或被另一实例覆盖关联。

重点审查数据库迁移与跨入口重复身份检查、GUI 已有实例复用、正常退出后再重启、旧 runId 事件隔离，以及静态根目录访问约束和退出清理。对应实测结果见验证记录，未覆盖的平台不得写成已验收。

1. `src-tauri/src/models.rs` 与 `src/types.ts`：配置、运行状态、会话与消息类型。运行状态不持久化为可接管的 PID。
2. `src-tauri/src/store.rs`：SQLite 迁移与 CRUD；外键级联只删除应用数据；已有记录更新不允许悄悄重建已删除的 ID。
3. `src-tauri/src/runtime/command.rs`：子进程私有环境、venv 搜索路径、图形界面启动时的 PATH 补充、Agent 参数与 shell 适配。
4. `src-tauri/src/runtime.rs` 与平台模块：PTY 生命周期、受管进程范围、端口归属、有界输出与消费确认。
5. `src-tauri/src/lib.rs`：每服务操作串行化、退出与新建进程之间的生命周期锁、托盘、单实例、文件导出。
6. `src/terminals.ts`、`src/components/TerminalPanel.tsx`：xterm 实例跨组件保留、顺序输入、消费完成后确认、主题和窗口尺寸变化。
7. `src/App.tsx` 与文档、配置组件：异步状态合并、草稿保护、保存失败与明确退出。
8. `src-tauri/vendor/portable-pty/补丁说明.md`：基于 0.9.0 保留许可证的两处 Windows 补丁，分别处理 ConPTY 光标继承与终止 API 返回值；升级依赖时需要重新核对。
9. `src-tauri/src/projects.rs`、`static_sites.rs`、`applications.rs` 与 `applications/`：类型化启动、静态 helper、桌面应用身份与退出边界。

## 关键行为

- 终端面板通过 `ResizeObserver` 测量父工作区的内容高度，扣除详情最小高度及面板间距；普通高度、展开高度和拖动上限使用同一限制。不能用整窗高度减固定值，否则运行提示条或详情最小高度会把末行推到窗口外。行列由实际容器重新计算；只有原本处于底部的会话才在重算后继续跟随，阅读历史不强制跳回。滚动入口订阅只随当前 DOM 挂载，退出页签时解除，不销毁会话。
- `runtime/command.rs` 为隔离的 bash、zsh、sh/dash 交互终端设置动态提示符，路径由 shell 在每次提示时展开，不能把启动目录当作实时目录。显式服务提示符配置优先；不加载 rc/profile、不改动服务及 Agent 的启动方式。Windows PowerShell/cmd 保持现有原生提示符，csh/tcsh 不在本次提示符修复范围内。

- 每个受管运行都有新的 `runId`。旧进程事件不能覆盖重启后的状态；命令服务操作按服务 ID 串行化。桌面应用的启动与关联等变更另有共享串行锁，避免两个记录同时启动同一路径的重复实例。
- 服务进程与独立 shell、Agent 是不同的会话。停止服务只结束服务输出对应的进程；删除服务和明确退出才结束相关的全部会话。
- macOS 根据 session 与 PID 启动标识确认受管进程，温和退出等待五秒后再强制清理。停止时重新确认已退出进程，防止快速重启或退出竞态产生错误的权限报告。
- Windows 使用同程序 helper，在目标进程的初始线程恢复前将其纳入 Job。helper 退出后先关闭 ConPTY master，并保持输出线程继续读取，随后才等待输出结束；Windows 10 不能假设最后一个控制台程序退出就会自动关闭 ConPTY 管道。
- 端口按受管进程及其子进程归属识别。预期端口被其他程序占用时单独列为冲突；进程存在不代表应用健康。
- 终端输出携带服务、会话、运行标识和序号。Rust 持续读取 PTY，采用有界缓存与有限在途消息；历史被截断时明确发送缺口信息。窗口隐藏或前端暂停消费不会无限占用内存，也不会停止读取服务输出。
- xterm 接收原始字节，负责跨块 UTF-8 解码。组件只挂载或移走终端 DOM，切换服务和主题不重建进程。
- 大段终端输入采用有界等待，停止流程不等待拥塞的输入锁。若输入未完整发送，界面会明确报告，避免把部分写入伪装成成功。
- 文档保存在 SQLite；Markdown 预览禁用原始 HTML。导出先写同目录临时文件，成功刷新后再原子替换目标，防止写入失败截断原文件。
- 关闭窗口隐藏到托盘；明确退出先处理未保存内容，再阻止新建进程并清理受管会话。重开应用恢复配置与文档，不自动重启服务。

## 实现边界

终端隔离包含当前目录、环境、输入和输出，不提供文件系统沙箱。主动脱离受管会话的守护进程不在首版管理范围内。环境和 Agent 使用用户已有安装，不自动安装运行时、依赖或登录工具。

浏览器预览拥有独立的数据命名空间，仅用于界面验收。首次桌面启动为空列表；浏览器示例配置不会进入桌面数据库。
