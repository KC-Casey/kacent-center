# 内容库与指令控制

内容库收藏文件夹、本地应用、游戏及已有桌面应用。它只保存入口与说明，不移动、删除或修改真实文件，不扫描游戏库。服务管理仍保留原来的命令、前端、静态站点和终端功能。

## 收藏和打开

从左侧进入“内容库”，点击“添加内容”，选择文件夹、应用或游戏。应用使用当前平台的 `.app` 或 `.exe`；游戏可选择本地应用或输入 Steam 数字 ID、`steam://run/<ID>`、`steam://rungameid/<ID>`。不接受任意协议、额外命令或查询参数。

名称用于展示；别名适合简短语音，例如将“2026 年设计资料”增加别名“设计资料”。标签和分组用于筛选，置顶和最近打开帮助找回常用入口。路径暂时不可用时保留收藏，可在编辑中重新选择。

已有桌面应用通过关联收藏进入内容库，原配置、文档和运行身份继续保留。移除这个收藏不会删除原桌面应用记录。新增内容应用不会创建虚假的命令服务或 PTY。

文件夹只显示目录可用性；本地应用只跟踪核验过的主实例。多个同路径实例需要明确选择，重开中心不会自动接管同路径的新实例。启动器转交无法核验时保留待关联；可选择已发现的同路径实例，或移除收藏后重新选择实际应用，不能把启动器退出当作应用已退出。Steam 启动仅表示已向协议处理器发送请求，不代表游戏已启动或可终止。移除收藏和完全退出中心均保留应用、游戏与实际文件。

## 文字和 Agent

在内容库底部选择一个支持中心指令的 Agent，再输入指令，例如：

- “打开设计资料。”
- “查找工作标签的收藏。”
- “显示浏览器。”
- “把设计资料置顶。”
- “移除旧的测试收藏。”

中心只把文字、候选条目的 ID、名称、类型、别名、分组和标签交给计划器，不发送文件正文、备注或进程环境变量。计划器使用独立任务进程；禁用执行工具、继承 MCP 和不受支持的扩展，返回结构化动作。后端再次校验范围、目标、版本及原生身份，然后执行允许的操作。

打开目录、启动、显示唯一目标直接执行；同名或模糊目标先选择。请求退出、移除收藏和批量编辑需确认，强制结束必须单独确认。新增或修改启动目标会进入预填表单，保存前不会执行新路径。取消停止后续动作，已经派发的系统调用可能仍会完成，打开操作不会自动撤销；重试同一请求标识不会再次执行。操作失败会显示实际执行器错误，Agent 说“成功”不代表动作已经完成。

此版本的指令入口只操作内容库，不能启动、停止或修改原命令服务、前端项目和静态站点。

Windows 中心计划器需要原生 `.exe` 入口，先挂起创建并纳入独立 Job 再恢复；`.cmd`／`.bat`／`.ps1` 安装入口会明确提示不可用于此模式，仍可使用普通终端或外部 MCP。Copilot 的私有配置目录用于隔离全局插件与 MCP；若登录仅保存在原目录，该调用会报告未登录，不复制凭据。

## 外部 MCP

打开“设置 → 内容控制与语音 → 外部 Agent 接入”，选择工具，复制该工具对应格式的配置片段，手动合并到已有配置。中心不覆盖全局配置，也不把认证令牌写进片段。开发版的隔离数据目录会作为 `KACENT_DATA_DIR` 写入片段，正式版通常不需要此变量。

本程序以 `--content-mcp` 启动标准 stdio 模式，在 Tauri 与单实例插件之前分流。它通过只绑定 `127.0.0.1` 的认证通道连接已经运行的中心。令牌在每次启动时重新生成，保存在数据目录的仅当前用户可读文件中。关闭中心后通道失效。

实际工具只有以下五项：

| 工具 | 功能 |
|---|---|
| `content_list` | 搜索收藏 |
| `content_status` | 查询一条收藏的实时状态 |
| `content_submit` | 提交带稳定 `requestId` 的结构化动作计划 |
| `content_task` | 读取任务状态与真实结果 |
| `content_cancel` | 取消未完成步骤 |

外部 MCP 没有确认、任意 shell、服务启动或文件删除接口。高风险动作返回等待确认，用户必须回中心窗口处理；附加 `confirmed` 参数不能绕过确认。

九种工具的预设都保留；终端可用、中心计划能力、外部 MCP 支持和实际测试结果分别记录。Aider 仅保留普通终端入口。没有可用 Agent 时仍可手动管理收藏。

## 本地语音

在设置中启用“按住说话”，明确下载或导入多语言 `ggml-base.bin` 模型（约 142 MiB）。下载和导入均核对固定模型摘要；模型不是 Python 依赖，识别引擎已随应用编译。模型不正确、下载失败或取消时不覆盖原可用模型。

按住内容指令栏的麦克风按钮录音，松开后转写并提交给选中的 Agent。键盘聚焦按钮后可按住空格或回车；Esc 取消。单次最多 60 秒，窗口失焦会取消，不持续监听，也没有全局唤醒词或语音播报。

原始音频仅保存在内存中，完成或取消后释放。**离线只指转写；转写后的文字及必要候选信息仍交给所选 Agent，沿用其本地或云端模型配置。** 无模型、无麦克风、权限拒绝、静音或识别失败均可退回文字输入。

macOS 首次录音需要系统麦克风授权。Windows 需要允许桌面应用访问麦克风。未访问真实设备的测试不能替代权限、设备断开与实际说话验收。

## 数据与开发

SQLite 版本 5 增加内容配置、独立应用身份关联及内容控制偏好。服务配置、文档和版本 4 的终端外观原样保留。运行状态与音频不写入内容表，系统句柄不持久化。

本地构建除原工具链外还需要 CMake，用来编译随应用发布的 whisper.cpp。用户运行安装包不需要安装 CMake、Rust 或 Python。一键调试脚本会检查 CMake 并给出缺失提示。

实际验证范围和待验事项见《验证记录》，设计取舍和人工审查重点见《架构与人工审查》。


## CLI 文档与版本差异

配置和限制参数会随客户端版本变化。中心会检查本机版本；不支持要求的参数时显示原因，不退回任意 shell 执行。实现参考 [OpenCode CLI](https://opencode.ai/docs/cli/)、[OpenCode MCP](https://opencode.ai/docs/mcp-servers/) 与 [Copilot 非交互接口](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-programmatic-reference)。这些文档核对结果不代表本机账号已经完成模型调用或 MCP 连接验收。
