## 界面约定

- 左侧服务列表是切换入口，搜索和状态筛选位于列表上方，新增服务入口紧邻列表标题。下方保留 AI 工具、设置和主题入口。
- 右侧顶部始终显示当前服务名称、进程状态与运行操作。主内容以“概览、环境、文档”组织；底部终端面板可调整高度。
- “服务输出”“终端 1”和具体 Agent 名称是不同会话的标签。选中某个终端，只呈现这个终端的内容。切换服务、标签和主题不结束会话。
- 进程运行与端口监听分别展示；绿色“运行中”不等同于健康检查通过。预期端口只是检查目标，修改它不会替用户修改启动命令或服务配置。
- 概览页目录是只读展示，附复制和系统打开操作；新增／编辑抽屉才是配置入口。路径较长时允许截断展示，但复制内容必须完整。
- 新增服务采用右侧宽抽屉，分为基本信息、目录与环境、运行配置、环境变量、备注。新建按钮为“创建服务”，不会自动启动；编辑时改为“编辑服务”和“保存修改”，新配置在下次启动时生效。
- 环境页承载已有环境类型、环境目录、自定义可执行文件目录和环境变量的查看与编辑，不加入依赖安装功能。
- 文档页采用文档列表与编辑区域，提供新建、编辑、预览、保存状态和 Markdown 导出。备注和文档默认保存在应用本地；预览不执行原始 HTML。
- Agent 选择入口提供 Codex、Claude Code、Gemini CLI 与自定义配置；它们在终端内运行，不另做应用内聊天界面。

## 视觉与适配

采用中性色背景、细边框、低圆角、蓝色主操作和清晰字重层级。运行、停止与异常均配文字，不能只用颜色区分。

深浅主题保持相同布局和操作位置；默认跟随系统，允许手动固定。侧栏、表单、文档和终端同时切换主题。图中 macOS 标题栏是平台示例，Windows 使用对应的原生窗口控制，内容布局保持一致。

工作台采用弹性分栏：侧栏约占参考图宽度的十八个百分点；右侧目录与端口区域在较窄窗口中上下排列，正文可滚动；终端保留独立高度。配置抽屉正文可滚动，底部按钮固定，不能遮挡最后一个字段。主要按钮不因宽度变化丢失标签。

## 图片与实现的边界

图片确定视觉方向和信息结构；交互、状态与准确文案以本文及《界面状态说明》为准。图片中的命令是排版示例，实施时使用正确的命令字符，不从图中识别连字符作为程序输入。例如配置图对应：

```sh
python -m uvicorn main:app --host 127.0.0.1 --port 8080
```
