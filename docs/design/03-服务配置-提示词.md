# 服务配置生成提示词

生成方式：内置 imagegen，以深色工作台为视觉参考生成新增服务界面。

参考图：`01-深色工作台.png`。

用途：ui-mockup。
交付物：中文桌面应用“服务中心”的新增／编辑服务表单高保真设计图。本张展示“新增服务”的实际界面，后续编辑服务沿用同一表单。参考图是此应用已生成的深色主工作台，必须沿用相同的视觉语言、字号风格、细边框、低圆角、蓝色强调色、图标体系和深色配色。不是让你重复主界面，而是以参考图中的工作台为背景，在右侧打开一个宽而清晰的配置抽屉。

画面：1920×1200、16:10，完整横向桌面应用正视截图，占满画布。无设备、无透视、无水印、无宣传语、无外部背景、无编号或设计标注。全部界面标题、说明、字段名和按钮使用简体中文。程序名、路径、命令及环境变量值保留原文。确保汉字清楚正确，正文不是小点。

构图：
保留顶部原生 macOS 窗口标题栏及左侧“服务中心”侧栏，在左边约30%可见范围内显示原有服务工作台并使用轻微半透明暗色遮罩；右边约70%为全高、非悬浮的配置抽屉，从原生标题栏下方一直到底部。抽屉背景深石墨灰，左边有细分隔边界。抽屉是画面焦点，左边背景弱化但不是模糊不可辨认。无需在背景里保留大块可读终端内容。

抽屉头部：左侧大标题“新增服务”，下一行“关联已有目录与环境，创建后可启动服务。”；右上角“×”关闭图标。
抽屉正文在高宽足够的空间内排布如下。只用分组标题、细分隔和留白组织，不要每个分组套一层厚重卡片。字段标签位于输入框上方。除明确说明的两列外，其余字段占整行。输入框高度适中，所有内容都完整露出，底部固定操作栏不得遮挡任何字段。

第一组标题“基本信息”。
两列：左侧标签“服务名称 *”，输入值“图像服务”；右侧标签“描述”，输入值“本地图像处理与生成接口”。

第二组标题“目录与环境”。
一整行标签“工作目录 *”，长输入框内容“/Users/kc/Projects/image-api”，右侧内嵌文件夹图标及“选择”按钮。
下一行为两列：左侧较窄，标签“环境类型”，下拉值“Python venv”；右侧较宽，标签“环境目录”，输入值“/Users/kc/Envs/image-api”，右侧文件夹图标与“选择”按钮。
该组底部小号但可读说明“使用已有环境，不自动安装依赖。”

第三组标题“运行配置”。
一整行标签“启动命令 *”，等宽单行输入框内容“python -m uvicorn main:app --host 127.0.0.1 --port 8080”。
下一行两列：左侧标签“终端”，下拉值“zsh”；右侧标签“预期端口”，输入值“8080”。
下方清晰说明“预期端口用于检查，实际监听端口将在启动后检测。”

第四组标题“环境变量”，右侧有小型“＋ 添加”文本按钮。
简洁的键值行，上方小标签“名称”“值”，一行两列输入值“APP_ENV”和“development”，末端垃圾桶删除图标。不要添加秘钥或密码示例。

第五组标签“备注”，短的多行文本框，值“仅供本地开发使用。”。

抽屉底部固定操作栏有细的上边界，左侧小号说明“创建后不会自动启动”，右侧两个按钮：次按钮“取消”，主按钮“创建服务”。表单的主要操作必须叫“创建服务”，不要叫“启动”。
正文和底部之间保留足够空白；分组间距紧凑适度，保证所有五组内容和底部按钮全部完整可见。务必忠实表达配置服务的实际产品界面，没有 AI 聊天框、文件树、容器管理或账号入口。
