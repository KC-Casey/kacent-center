# 深色工作台生成提示词

生成方式：内置 imagegen。

用途：ui-mockup。
交付物：中文桌面应用“服务中心”的高保真深色工作台设计图。这是一张可直接指导 React + Tauri 实现的完整桌面应用界面，不是宣传海报。画布为清晰的 1920×1200、16:10 横向截图，正视图，界面占满画布，不要设备外壳、透视、外部背景、手持设备、水印或界面外说明。所有界面标题、说明、按钮及状态文案使用简体中文；只允许 CLI 工具名称、技术术语、路径和命令保留英文。中文必须工整、清晰、可读。

产品用途：在本机管理多个命令型服务，每个服务有独立目录、环境、运行进程、端口、文档以及独立 AI Agent 终端。只展示实际可实现的界面；不要云端账户、收费、聊天气泡、虚构性能图表、CPU仪表盘或大幅装饰。

整体视觉：精致克制的专业桌面工作台；深石墨灰背景、稍浅的中性色面板、非常细的边线、低饱和冷色主操作按钮。层级主要由空间、字重与对比建立，避免彩色面板堆叠、巨大圆角、渐变、发光、毛玻璃、阴影悬浮卡片。正文清晰易读，终端使用规整等宽字体。图标是统一细线图标。约8像素圆角、舒适紧凑的间距，留白恰当。不可因为内容多而把正文缩成小点。顶部为很薄的原生 macOS 标题栏，左侧红黄绿窗口控制，正中“服务中心”。
