# 界面状态与交互说明

本说明补齐静态设计图无法同时展示的状态，并记录命令服务、前端项目、静态站点与桌面应用的交互差异。

## 空列表

标题：“还没有服务”。

说明：“添加本地服务后，可在这里管理目录、运行状态、终端和文档。”

主要操作：“新增服务”。首次使用不把设计图中的演示服务写入真实列表。搜索没有结果时改为“没有找到匹配的服务”，提供“清除筛选”，保留已有服务数据。

## 启动失败与异常退出

无法创建进程时显示“服务未能启动”，说明区域呈现后端返回的可读原因，例如“找不到启动程序，请检查命令和环境”。操作：“编辑服务”“重试启动”。

进程启动后异常结束时显示“异常退出”，列出退出码，保留本次服务输出。操作：“查看服务输出”“编辑服务”“重新启动”。不以通用成功提示覆盖实际错误，也不擅自自动重启。

桌面应用没有服务输出终端，详情展示原生启动、关联或退出结果。无法确认启动器交接目标时显示“待关联”，允许选择运行中实例，不伪造启动成功或终端输出。

## 目录失效

概览页提示：“工作目录不可用，请重新选择目录。”

已有虚拟环境失效时提示：“环境目录不可用，请检查路径或选择其他环境。”

操作：“编辑服务”。关联目录不可用时禁止新的启动操作；已运行进程仍可停止，不因为路径消失而禁用停止按钮。编辑抽屉在对应字段下显示明确原因，缺失必填目录时不允许提交。复制路径仍可用，无法打开的目录不得显示打开成功。

桌面应用与外部接入记录允许暂缺工作目录；有效工作目录是新建独立终端或 Agent 的前提。桌面应用启动单独核验目标 `.app`／`.exe`，不将可选的终端工作目录当作必填启动条件。

## Agent 未安装或路径失效

标题：“无法启动所选 Agent”。

说明：“未找到可执行程序，请安装对应 CLI，或在 AI 工具设置中指定程序路径。”

操作：“编辑工具配置”“重新检测”；允许打开普通终端供用户自行处理。检查失败不产生一个看似正在运行的 Agent 标签，不自动安装工具，不创建应用内模型账号或密钥流程。

## 端口状态

| 情况 | 展示与动作 |
| --- | --- |
| 受管进程实际绑定端口 | 列出地址、端口和 TCP／UDP；TCP 显示监听，UDP 显示绑定 |
| 预期端口被其他进程占用 | “预期端口 {端口} 已被其他进程占用。”提供查看服务输出和编辑服务入口，不把该端口算作当前服务 |
| 进程运行，但未发现预期监听 | “进程正在运行，尚未检测到预期端口。”保留实际探测结果 |
| 探测失败或权限不足 | “暂时无法获取端口信息。”呈现具体原因，不显示为“无端口”或健康状态 |
| 未配置预期端口 | “未设置预期端口”；仍显示探测到的实际端口 |

修改“预期端口”仅修改检查目标。若要改变实际端口，用户需要修改启动命令或服务自身配置。界面不提供杀死未知占用进程的快捷操作。

## 文档保存状态

正常保存成功显示“已保存”；编辑后显示“有未保存的修改”，提供“保存”。切换服务或文档时保留当前草稿，不静默丢弃。

保存失败显示：“文档保存失败，编辑内容已保留，请重试。”提供“重试保存”“复制内容”，不得把失败状态标为已保存。导出失败显示原因并保留原文档。

明确放弃修改或退出应用可能丢失草稿时，提示“有未保存的修改”，提供“保存后继续”“放弃修改”“取消”。这是保护实际未保存内容的交互，不是每次关闭窗口都弹出的确认。

## 删除服务与关闭终端

删除无活动会话的服务时提示：“将删除此服务的应用记录、备注和文档，不会删除工作目录或环境目录。”操作：“取消”“删除服务”。

平台托管的命令服务、前端项目或静态站点存在运行进程或终端时，说明列出将结束的服务进程和终端数量，主操作为“停止并删除”。停止失败时保留服务记录及错误状态，不假装删除完成。

桌面应用与外部接入服务删除时只解除关联，明确说明原应用／进程继续运行；中心为该记录创建的独立终端仍提示并关闭。删除确认不能把保留运行的应用列入将结束的进程。

“停止服务”只停止该服务的受管运行实例，不结束普通终端或 Agent 会话。“服务输出”随服务生命周期管理，不提供普通终端的关闭按钮。普通终端与 Agent 标签可独立关闭；有活动进程时提示将结束此会话，其他终端不受影响。

## 运行按钮

下表适用于平台托管的命令服务、前端项目与静态站点；实际操作以后台返回的能力与不可用原因为准。

| 状态 | 启动 | 停止 | 重启 |
| --- | --- | --- | --- |
| 已停止／异常退出 | 可用，配置有效时 | 禁用 | 禁用 |
| 启动中 | 禁用 | 禁用，直到启动操作完成 | 禁用 |
| 运行中 | 禁用 | 可用 | 配置有效时可用 |
| 停止中／正在重启 | 禁用 | 禁用 | 禁用 |

操作执行期间显示相应进度文案并阻止重复点击。重启按停止旧实例、确认回收、启动新实例顺序进行。过期运行事件不能把新实例的状态改回已停止。

桌面应用提供“启动”“显示应用”“请求退出”“重启”，强制结束使用独立确认。请求退出等待五秒未结束时保留跟踪，不自动升级为强制结束；重启必须确认原实例已退出。同路径多个运行实例由用户选择。没有窗口、权限不足或身份不明时显示后台返回的具体原因。

## 键盘、主题与窗口

- 焦点顺序遵循阅读顺序；输入框、页签、图标按钮与主要操作都有可见的键盘焦点。纯图标按钮提供中文名称或提示。
- 终端聚焦时，Ctrl+C 传递给当前会话；文本复制使用平台适合的快捷键和明确的复制入口，避免误中断其他会话。
- Esc 关闭无未保存内容的菜单或抽屉；有实际未保存修改时执行前述保留或确认规则。
- 工作台主题与终端外观独立设置。终端默认跟随系统深浅模式，也支持固定预设、自定义颜色、字体、行高和光标。保存前显示独立预览，未保存时关闭会询问是否放弃；保存后保留服务选择、终端连接与历史输出，字号变化会重新计算终端行列。运行状态配合文字，禁用操作仍保持可辨识。
- 窄窗口下通过正文滚动和分栏重排保持可用，终端与固定底部操作区不遮挡字段，不新增移动端布局范围。
- 关闭窗口隐藏到托盘，运行进程和会话继续保留。托盘操作名为“显示窗口”和“停止托管服务并退出”；明确退出时停止平台托管的命令服务、前端项目、静态预览和全部独立终端，并处理未保存文档。桌面应用与外部接入进程继续运行。
- 终端工作目录和环境隔离不等于文件系统沙箱，不以“安全沙箱”等文案描述会话。
